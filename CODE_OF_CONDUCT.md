# Code of Conduct

## Our commitment

We are committed to providing a welcoming, respectful and inclusive environment for everyone,
regardless of experience, background or identity.

## Expected behavior

When participating in this project, please:

- Be respectful and constructive.
- Be open to feedback and different opinions.
- Help create a friendly and collaborative environment.
- Focus discussions on improving the project.
- Assume good intentions from others.

## Unacceptable behavior

The following behavior is not tolerated:

- Harassment, discrimination or personal attacks.
- Insults, offensive language or abusive behavior.
- Trolling, intentional disruption or spam.
- Sharing other people's private information without their permission.
- Any other conduct that would make others feel unwelcome.

## Reporting issues

If you experience or witness unacceptable behavior, please contact the project maintainer
([Ivole32](https://github.com/Ivole32)) privately. All reports will be handled respectfully and,
where possible, confidentially.

Security vulnerabilities are not conduct issues. Please report them as described in
[SECURITY.md](SECURITY.md).

## Enforcement

The project maintainer reserves the right to edit, remove or reject comments, issues, pull
requests and other contributions that violate this Code of Conduct. Repeated or severe
violations may result in temporary or permanent exclusion from the project.

## Scope

This Code of Conduct applies to all project spaces, including GitHub issues, discussions, pull
requests and any other communication related to the project.

Thank you for helping make Uptime Status a welcoming project for everyone.
